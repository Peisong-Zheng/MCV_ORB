# Detailed chronology checks

These reproducible diagnostic outputs support code and method verification.
They are kept outside the compact research tables in
`MIS6/data/processed/MIS6_event_age_uncertainty/` and are regenerated by
`MIS6/MIS6_event_age_uncertainty.ipynb`. They are not unit-test fixtures or required
inputs for the pooled PI analyses.

| File | Purpose |
| --- | --- |
| `definition_picks_and_chronology.csv` | All 189 event picks (21 events × 9 settings), MF bound repairs and working chronology scales. |
| `sofular_raw_control_diagnostics.csv` | All 31 source U–Th dates, units, depths, model ages and model-minus-measurement residuals. Includes So-4's younger segment, which is not used for MIS 6. |
| `sofular_event_depth_projection.csv` | Event-to-component projections, dated brackets and interpolation weights for both schemes at zero mapping lag. |
| `sofular_component_mapping_sensitivity.csv` | Local error scales for different assumed age-coordinate mapping lags. |
| `sofular_component_mapping_covariance.csv` | Covariances implied by the shared control errors, before monotonicity/order conditioning. |
| `mis6_event_age_uncertainty_summary.csv` | Complete primary summary, including 16th/84th percentiles and chronology-scale variation across detector settings. |
| `mis6_event_age_uncertainty_summary_so57_overlap.csv` | The corresponding complete alternative summary. |

The two full summaries retain 16 columns. The research directory holds a
10-column selection from each; no event rows or MC realizations are dropped.
The relocation preserved the original diagnostic tables and complete summaries.
Covariance checks here describe proposed errors, whereas the plotted empirical
correlations describe the accepted joint MC ensemble.
