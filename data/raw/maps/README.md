# Map background

[ne_110m_land.geojson](ne_110m_land.geojson) is the Natural Earth 1:110 million
land layer, [version 5.1.2](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_110m_land.geojson).
Natural Earth data are [public domain](https://www.naturalearthdata.com/about/terms-of-use/).

[Figure_orbital_mechanism.py](../../../Figure_orbital_mechanism.py) uses this
modern coastline for geographic orientation. The ocean shading, ice and arrows
are conceptual illustrations, not reconstructed glacial boundaries or model
output. The local coastline file allows the figure to be drawn offline.
